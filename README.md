# L&G DJ, Sound & Light — Official Website

Bilingual (**Slovenian / English**) static website for **L&G DJ, Sound & Light** (Luka — DJ Vant & Gašper), designed to be hosted directly on **GitHub Pages**.

## Features
- **Bilingual (SL / EN):** Instant language toggle in the header with `localStorage` persistence.
- **Email Shortcuts Only (No Online Forms):** Pre-filled `mailto:` templates in both Slovenian and English for **Private Parties (`Privat zabave`)**, **Weddings (`Poroke`)**, and **Corporate Events (`Poslovni dogodki & zabave`)** addressed to `djvantmusic@gmail.com`.
- **Clear Legal Notice:** Explicitly states that you work exclusively via **student referral (`študentska napotnica`)** and do not have a registered business (`nimava registrirane dejavnosti`).
- **Facebook Assets Included Locally:** Uses the official logo (`assets/images/logo_profile.jpg`) and setup photos (`assets/images/photo_1.jpg`, `assets/images/photo_2.jpg`) from your Facebook profile.

## Hosting on GitHub Pages
1. Create a new repository on GitHub (e.g., `lg-dj-sound-light`).
2. Push the files in this folder (`index.html`, `styles.css`, `script.js`, `.nojekyll`, and `assets/`) to the `main` branch.
3. In your GitHub repository, go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch** → choose `main` and `/ (root)` → click **Save**.
